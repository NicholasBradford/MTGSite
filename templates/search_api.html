Inventory Search Syntax Guide

Overview

Our search engine supports advanced token-based querying. You can search by simply typing a card name, or use specific tags like type: or usd> to narrow down your inventory.

Example: bolt t:instant usd<2 -s:m11
Finds cards with "bolt" in the name, that are instants, cost less than $2.00, and are NOT from the M11 set.

Basic Search (Names & Phrases)

Any word without a prefix is treated as a card name. If a name has spaces, wrap it in double quotes.

  • jace — Finds cards with "jace" in the name.
  • "jace beleren" — Finds exact phrase matches.

Supported Filters

Use these prefixes followed by a colon : to target specific card attributes.

Prefix Shorthand Description Example
set: s: Search by 3-letter set code. s:uma
type: t: Search by card type (e.g., creature, instant). t:elf
color: c: Search by card color. c:u
identity: id: Search by Commander color identity (matches cards containing any selected identity color). id:u
oracle: / text: o: Search the rules text of the card. o:"draw a card"
location: loc: / l: Search by physical storage location (by ID or string name). loc:"Trade Binder"

Mathematical Operators

For numeric values like Quantity and Price, you can use mathematical operators instead of colons: >, <, >=, <=, =, !=.

Prefix Shorthand Description Example
usd - Filter by current market price. usd>5.00
quantity qty / q Filter by the number of copies. qty>=4

Negation (-)

You can invert any search token by placing a hyphen - directly in front of it. This tells the engine to exclude results matching that token.

  • -t:creature — Excludes all creatures.

  • -id:c — Excludes colorless identities.

  • -usd>10 — Excludes cards over $10 (effectively meaning usd<=10).

Sorting Results

You can control the order of your results directly from the search bar using the sort: operator.

Example: t:dragon sort:usd

Available Sort Options:

  • sort:name (Default) — Alphabetical

  • sort:rarity — Mythic → Rare → Uncommon → Common.

  • sort:usd — Highest price first (factors in foil pricing).

  • sort:set — Set code, then by Collector Number.

  • sort:location — Location name, then alphabetical.

  • sort:added — Most recently added to your inventory first.
